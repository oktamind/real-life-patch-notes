Entrants write one line, at most 160 characters: a software patch note or changelog entry for a bug in real life or human biology, in the terse register of a real release note. A judge compares patch notes two at a time and picks the funnier one.

This entry's patch note is **v1.3.7: fixed a bug where noticing your breathing switched it to manual mode, with no auto-resume.** — the moment you notice your breathing, it switches to manual, and reading the note triggers it in the reader.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes exactly one line to `out/entry.txt` (98 characters, no trailing newline), deterministically.
